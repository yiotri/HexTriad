# HexTriad
HexTriad is a two-player abstract strategy game where you place squares, circles and triangles on a small grid, completing square–circle–triangle triads that collapse into permanent hexes. 

The core offers a compact testbed for modeling the economic behavior of intelligent agents: players spend a scarce, depletable resource, build on each other's investments, and weigh uncertain payoffs against an adaptive opponent. It is also well suited to benchmarking AI agents of any kind, from search programs and reinforcement learners to LLMs.

The source code for a light but playable version is available alongside a more polished, compiled version for fun: play a friend on the same screen or challenge the built-in bot.

Included: generative music from games played by four AI agents, each trained under its own set of rules. Eight tracks are sonification of their games, every move a note: four duels as drum-machine pads, and four as two pianos drifting apart. Nine more tracks come from the game's soundtrack, synthesized in real time.

## Folders
